# 🍃 Foodies – Healthy Food Landing Website

Welcome to **Foodies**. A clean, modern, veggie-loving landing page where design tastes as fresh as the food it promotes.  
This project showcases delightful UI, smooth layout, and attention to detail using **HTML + CSS**.

---

## ✨ Features

• Fully designed hero section with product highlights  
• Flexbox-based responsive structure  
• Clean typography using Poppins font  
• Brand showcase, benefit section, product & feature visuals  
• Beautiful footer layout with external author link

---

## 🧩 Tech Stack

- HTML5
- CSS3 (Flexbox Layout)
- Google Fonts (Poppins)
